Glyph does not come with a catalogue. It comes with a browser and an empty
shelf, and the first thing you do is add a repository. It takes about five
minutes, most of which is choosing what to read.

## Add the repository

Open **Settings → Extensions** and tap the plus button. Paste a repository URL
— these are shared by the community — then tap **Fetch**.

The app reads the repository and lists the sources inside it. Nothing is
installed yet; this is the part where you find out whether the repository is
still maintained.

Tap **Install**. Installed sources appear in the Browse tab immediately.

## Browse, search, read

- **Browse** lists your sources as cards. Open one to see featured novels,
  popular titles, and genres.
- **Search** runs one query across every installed source at once, grouped by
  where the results came from.
- Tap a novel for its detail page, then a chapter to start reading.

## When it does not work

A repository that fetches but installs nothing usually means the source is
marked broken or targets a site that changed its markup. Refresh the source in
Settings → Extensions. If the repository itself fails to load, the URL is wrong
or the host moved.

> Nothing is cached on a server Glyph runs, because Glyph runs no server. If a
> source stops working, it stops working for everyone at once, and an update is
> the only fix.
