# Library

The **Library** tab is where every novel you've added lives. Glyph keeps the list on your device and syncs it across your other Apple devices via iCloud.

## Adding a novel

Open any novel from Browse or Search → tap the **bookmark** icon in the toolbar. The novel appears in Library immediately. To remove it, tap the same icon again, the novel stays installed and you can re-add it any time.

## Folders

Group novels by genre, mood, status, or anything else. Tap the **folder** icon in the Library toolbar to manage them.

- **Create** a folder: tap **+**, give it a name.
- **Rename / delete**: long-press the folder name.
- **Move a novel**: long-press the cover → drag into a folder.

A novel can only be in one folder at a time. The default "All" folder holds anything not assigned elsewhere.

## Sort options

Tap the sort icon at the top to change the order:

| Option                           | Behavior                                        |
| -------------------------------- | ----------------------------------------------- |
| **Recently Updated** _(default)_ | Novels with new chapters first, grouped by date |
| **Title**                        | A → Z                                           |
| **Date Added**                   | Newest in your library first                    |
| **Last Read**                    | What you opened most recently                   |

## Badges

In **Settings → Library**, two optional badges on each library cover:

- **Unread**: number of unread chapters
- **Downloaded**: number of chapters available offline

Both off by default. Turn them on if you want at-a-glance status without opening each novel.

## EPUB & PDF import

Glyph reads local files alongside extension-fetched novels.

1. Library → toolbar → **Import file**
2. Pick a `.epub` or `.pdf` from Files, iCloud Drive, or on-device
3. The book appears with its embedded cover and metadata

Imported books support the same Reader features as extension novels, themes, bookmarks, fonts, search-in-chapter. They have no "source" and don't check for updates because they're self-contained files.

## Novel detail

Tap any library novel to open its detail page:

- Cover, title, author, description, tags
- Full chapter list with read / unread state
- **Download** menu in the toolbar (per-chapter or all)
- **Bookmark** to add or remove from Library
- **Refresh** to re-fetch metadata and chapter list from the source

## Removing a novel

Swipe left on a novel in Library to remove it. The novel itself stays installed, you can re-add it from Browse. Removing also clears its reading history and downloaded chapters.
